# SpriteCook art

1. Sign in at app.spritecook.ai, open the kit's review page (`review_url` in `kit-landscape.json`) and download the Unity archive.
2. Unzip its images into this folder.
3. In Unity: **Sailor's Rest → Apply SpriteCook Import Settings**. Every image gets point filtering, no compression, and the 9-slice border listed in `kit-landscape.json`.
